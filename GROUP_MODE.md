# Habibi — Group mode

Set in `.env`:

```
AGENT_MODE=group
```

## Included
- Group moderation (antilink, antistatus, kick, promote, welcome, tag-all, …)
- Games & fun (when enabled)
- Utilities: weather, translate, notes, reminders, media download, image/video gen, search, stickers, polls, memes, economy helpers, etc.

## Not included
- Git / GitHub / repo agent
- Project builds, zip fix, dev shell, npm tooling, architecture reviews

MAIN FILE = `boot.js`
